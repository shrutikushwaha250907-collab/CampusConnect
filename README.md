# 🎓 CampusConnect

CampusConnect is a Flask-based student collaboration platform that helps students create profiles, share skills, and upload academic notes. The project is built using Python, Flask, SQLAlchemy, SQLite, HTML, CSS, and Bootstrap.

---

## 🚀 Live Demo

🔗 https://campusconnect-l3gb.onrender.com

---

## 📌 Features

- 👤 User Registration & Login
- 📋 Student Dashboard
- 📝 Profile Management
- 💼 Skill Marketplace
- ➕ Add Skills
- ❌ Delete Skills
- 📚 Upload Notes
- 📥 Download Notes
- 🗑 Delete Notes
- 🔒 User Session Management
- 📱 Responsive Bootstrap UI

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/CampusConnect.git
```

Move into the project:

```bash
cd CampusConnect
```

Create a virtual environment:

```bash
python -m venv env
```

Activate the environment:

### Windows

```bash
env\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

Open your browser:

```
http://127.0.0.1:5000
```
